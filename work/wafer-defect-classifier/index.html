Wafer Defect AI Classifier

Role

Designer & developer

Category

Deep Learning / Semiconductor

Year

2026

Status

95.9% validation accuracy

Overview

An end-to-end deep learning system for automated yield inspection. A convolutional neural network trained on the WM-811K dataset recognizes 8 failure patterns on wafer maps, such as Scratch, Donut and Edge-Ring, reaching 95.9% accuracy on unseen validation data. Grad-CAM heatmaps show which areas of the wafer drove each decision.

What I did

  1. 01Cleaned the WM-811K dataset and normalized every wafer map to a 26 × 26 grid
  2. 02Designed and trained a CNN that classifies 8 defect patterns
  3. 0395.9% accuracy on unseen validation data
  4. 04Grad-CAM heatmaps that make each prediction explainable
  5. 05A simulated production monitor that checks a lot of wafers like a fab dashboard
